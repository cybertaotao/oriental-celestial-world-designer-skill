## 它解决什么问题

这个 Skill 面向“东方神话超大规模建筑文明”的视觉设计。它会先解决镜头、空间、尺度和透视，再补全材质、云海、光影与提示词；因此输出不只是形容词堆叠，而是一套可执行的场景方案。

默认世界观为东方云上天宫：以唐宋官式古建筑为基础，使用文明级放大的台基、柱网、斗拱、重檐与宫阙群，配合云海、空气透视和克制的电影摄影语言。

## 核心原则

1. **先设计空间，再设计细节。** 先确定镜头、前中远景、消失点和空间路径，避免材质与装饰掩盖构图问题。
2. **建筑是主体，人物只是尺度参照。** 默认仅使用 1–3 名中远景人物，并建立建筑相对人物约百倍或更大的感知体量差。
3. **允许神话尺度，禁止廉价游戏仙侠审美。** 神话感来自海拔、建筑秩序、云雾遮挡与不可见的空间延伸，而不是法阵、粒子、霓虹和满屏金光。

## 功能

- **场景创意设计**：给出 3–8 个空间结构真正不同的场景方案，而不是只换名称或装饰。
- **从零生成提示词**：把主题转化为完整的镜头、建筑、空间、人物、材质、光线和负面提示词。
- **参考图视觉反推**：分析镜头位置、景深层级、消失点、人物比例、云海与光源；忽略水印、字幕、Logo 与界面元素。
- **提示词精修**：保留原始意图，针对性加强巨构尺度、空间纵深、真实材质或电影感。
- **统一世界观控制**：稳定使用唐宋官式结构、象牙白风化石材、暗朱红木构、深青灰屋顶及低饱和色彩系统。
- **电影摄影语言控制**：默认采用 16:9、65mm 大画幅胶片质感与 24mm 超广角，并明确机位、朝向和引导线。
- **强制防翻车检查**：在交付前自动检查人物抢画面、廉价仙侠 CG、建筑失真、透视冲突、塑料材质、滥用金光及信息过载。

## 适用场景

适合处理：

- 东方天宫、云上宫殿、云海宫阙
- 巨型天门、礼制祭坛、神殿、白玉石桥、云崖宫殿
- 超大中式古建筑奇观与东方仙境电影场景
- 参考图反推东方巨构提示词
- “建筑再宏大一点”“人物更小”“加强消失点”“降低手游 CG 感”等定向优化

## 安装

将本仓库放入 Codex 的 Skills 目录，使文件夹名保持为 `oriental-celestial-world-designer`：

```bash
git clone https://github.com/cybertaotao/oriental-celestial-world-designer-skill.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/oriental-celestial-world-designer"
```

Windows PowerShell 示例：

```powershell
git clone https://github.com/cybertaotao/oriental-celestial-world-designer-skill.git `
  "$env:USERPROFILE\.codex\skills\oriental-celestial-world-designer"
```

重启或刷新 Codex 后，即可通过 `$oriental-celestial-world-designer` 调用。

## 快速开始

```text
使用 $oriental-celestial-world-designer 为我设计 5 个空间结构完全不同的云上天宫场景。
```

返回结果会先提供场景名称、核心概念、主建筑、镜头构图、尺度表现与视觉亮点；需要时再展开为正式提示词。

```text
使用 $oriental-celestial-world-designer 设计一座位于云海之上的巨型天门：清晨侧逆光，人物极小，强调低机位、长消失点与真实唐宋古建结构。
```

```text
使用 $oriental-celestial-world-designer 分析这张参考图，保留它的长廊透视和云海层次，并生成更真实、克制的东方巨构提示词。
```

### 精修已有提示词

```text
使用 $oriental-celestial-world-designer 优化下面的提示词：让建筑拥有文明级尺度，人物更小，消除塑料材质和廉价仙侠手游 CG 感。
```

## Skill 如何工作

每次正式生成或优化时，Skill 在内部按以下顺序工作：

1. 确定场景命题与唯一主视觉建筑。
2. 确定画幅、焦段、机位、高度与镜头朝向。
3. 建立至少五层空间：近景巨构、中景尺度标尺、纵深结构、远景锚点和极远世界层。
4. 用柱列、长阶、栏杆、屋檐、桥梁或地砖服务一个明确主消失点。
5. 建立极端建筑/人物尺度反差，并将人物退至中远景。
6. 组织可信的唐宋建筑结构和真实石、木、瓦、玉石材质。
7. 用多层云海、绕雾和空气透视表达高度与世界的无尽延伸。
8. 以克制暖金侧逆光与冷青灰漫射光完成电影级明暗关系。
9. 执行防翻车门禁，再输出连贯的正向与必要负面提示词。

## 默认视觉 DNA

| 维度 | 默认方向 |
| --- | --- |
| 建筑 | 唐宋官式结构、礼制中轴、层层台基、连续柱廊、稳定斗拱与重檐 |
| 尺度 | 建筑是主体；人物为 1–3 名、背身或侧后、极小的尺度标尺 |
| 摄影 | 16:9、65mm 大画幅胶片质感、18–35mm 广角，优先 24mm 低机位 |
| 材质 | 象牙白风化石材、暗朱红木构、深青灰瓦顶、低调反射的天然玉石地面 |
| 色彩 | 象牙白、暗朱红、深青灰、墨绿与低饱和青灰天空 |
| 光影 | 清晨暖金侧逆光；建筑主体保持冷青灰漫射光；丁达尔光只用于空间深度 |
| 大气 | 云下厚云、建筑腰部绕雾、贴地薄雾、远景空气透视 |

## 输出原则

Skill 会适配用户指定的生图模型或语法；如果未指定，默认使用中文输出连贯提示词。它不会杜撰模型参数，也不会用大量同义形容词填充长度。

最终结果必须满足：建筑先于人物和特效被看见；透视方向清楚；材质具有天然纹理和细微瑕疵；云海承担空间功能；金色只作为光线和局部高光；画面不出现动漫、手游 CG、塑料材质、魔法光效或无关装饰堆砌。
