## 1. 空间先行法

在加入纹样、服饰、材质和光效前，先写出一条空间骨架：

> 镜头位于何处 → 最近的巨构是什么 → 人物站在哪里 → 哪些线条通往哪里 → 主殿或天门位于哪个景深 → 世界如何在云雾中继续。

若这条骨架无法形成清楚画面，继续调整空间，不要用细节掩盖问题。

优先确定一个主视觉建筑。其他宫阙作为层级、节奏或远景回声，不与主建筑争夺中心。

## 2. 五层以上空间结构

默认建立至少五个可辨识景深层：

1. **贴近镜头的框景层**：越出画框的巨柱、飞檐、斗拱、石栏、古松枝或台基边缘。
2. **近景承接层**：玉石地砖、长阶起点、桥头、柱廊入口或檐下暗部。
3. **中景尺度层**：1–3 名微型人物、连续栏杆、柱列、祭坛或平台。
4. **远景主锚层**：主殿、天门、祭坛中心、长廊尽头或横向宫阙。
5. **极远世界层**：多重宫阙轮廓、山体、云海裂隙与逐渐消失的建筑群。

必要时加入第六层“天空/云上缘”和第七层“倒影/雾中隐约结构”。强镜像地面可以成为独立景深层，但必须与实体地面共享同一透视，并通过拼缝、石纹、雾气或粗糙度与真实空间区分。每一层需在尺寸、清晰度、对比或遮挡上与相邻层不同。

## 3. 主消失点设计

每幅画先指定一个主消失点，再选择 2–4 组引导线共同指向它：

- 柱脚与柱顶的连续边线。
- 石阶两侧、栏杆和扶手。
- 屋檐下缘、梁架或长廊顶线。
- 地砖拼缝或玉石铺装接缝。
- 石桥边缘、台基轮廓或云层裂口。

把主消失点落在主殿、天门、长廊尽头、云崖尽头或祭坛核心。允许次级透视说明侧翼空间，但不得与主透视争夺方向。

### 纵深增强方法

- 让相同柱列或栏杆以可读节奏连续缩小。
- 让近景构件部分越框，远景构件在雾中消失。
- 使用前景遮挡和建筑互相叠压，避免所有物体平铺。
- 让地面拼缝在近处宽、远处密。
- 在消失点附近压低对比，不用强光点强行吸睛。

### 禁止做法

- 同一长廊出现两个互相冲突的汇聚方向。
- 柱脚、柱顶和地砖各自指向不同中心。
- 用鱼眼畸变制造“大”，导致直柱弯曲。
- 把主建筑贴在背景中央而没有通往它的空间路径。

仪式性天门、神道、巨大月洞允许严格中央对称。对称构图必须依靠道路、柱列、门框厚度、倒影和远景对位建立秩序，而不是仅把一个建筑正面贴在画面中央。

## 4. 镜头与机位选择

### 24mm 贴地低机位

用于长阶、柱廊、天门、巨柱神殿。让镜头接近地面，以地砖、阶沿或柱基占据前景，向上或向深处看。优势是压迫感和长消失点；风险是垂直线过度倾斜、人物被近大远小放大。

### 28–35mm 檐下回望

用于框景与内外明暗对比。镜头位于巨大檐下或门洞内，前景暗，向外看云海宫阙。优势是结构厚度和层层揭示；风险是黑色前景面积过大。

### 18–24mm 横向云崖视角

用于横向宫阙和云海平台。镜头沿崖壁或长廊斜向观察，让建筑横向延伸并被云雾分段遮挡。优势是展示文明带状扩张；风险是画面变成平直全景图。

### 24–35mm 广阔高空视角

用于主殿群、环形祭坛或多级台基。保持斜俯视而非垂直鸟瞰，让建筑立面仍可辨识。优势是展示礼制总图；风险是人物完全失去标尺作用或场景像建筑沙盘。

## 5. 尺度控制

不要依赖抽象形容词。至少放入三类可见证据：

1. **人物证据**：人物不足柱基高度的一小部分，或需要跨越漫长平台才能抵达主殿。
2. **重复证据**：数十根柱、连续台阶、栏杆或瓦檐逐渐缩小到雾中。
3. **遮挡证据**：构件越框、建筑腰部被云遮挡、远端无法看到尽头。
4. **层级证据**：主殿之外仍有更远的台基、宫阙与云中轮廓。

将人物置于有明确接触面的地面或台阶，不漂浮，不放在容易被误读为巨人的前景。人物越靠近镜头，越要进一步缩小或移至侧边。

## 6. 构图家族

用空间拓扑区分方案：

- **轴向推进**：长阶、长廊或桥梁直达主殿，单点透视强。
- **横向展开**：宫阙沿云崖或山壁延伸，以层叠遮挡显示广度。
- **放射汇聚**：环形祭坛或多条路径朝中心汇聚，强调礼制和仪式。
- **门洞框景**：通过天门、檐下或柱间开口观看远方核心建筑。
- **月洞框景**：以巨大圆形开口包围月轮、孤峰或云海，室内深色实体与室外高空形成几何对照。
- **天象对位**：让巨大月轮与天门、长廊、神道或祭坛主轴精确对齐，以建筑路径引导至天象锚点。
- **垂直压迫**：贴近巨柱、台基或门楼向上看，以垂直尺度为主。
- **跨越深渊**：长桥连接云海两端，使用桥缘和栏杆制造纵深。
- **多级揭示**：院落、门、台基、主殿依次出现，强调文明序列。

生成多个场景时，优先从不同家族各选一个，而非在同一家族里换装饰。

## 7. 镜像地面与天象对位

### 镜像地面

先设计实体透视，再添加倒影。让地砖拼缝、柱脚、栏杆和建筑轮廓决定反射方向：

- 白玉镜面适合晨昏暖光、白色天门与开阔神道；玄玉镜面适合朱红柱廊、月洞室内和檐下暗部。
- 强镜像场景保留一块清楚倒影作为视觉亮点，其他区域用石纹、薄雾、磨损或视角衰减打散。
- 倒影可延长柱列和人物轮廓，加强垂直尺度，但不能比实体更亮、更锐或出现不对应物体。
- 人物脚部必须与地面接触，倒影从接触点开始，避免漂浮。

### 巨大月轮与主轴

- 月轮占据圆形门洞或天门背景时，把圆心放在主轴或有意偏移的位置，并说明这种对位关系。
- 让长廊檐线、神道边缘、柱列或门框把视线送向月轮；月轮是远景终点，建筑仍是构成空间的主体。
- 月轮边缘受薄雾和空气透视柔化，表面细节在明部清楚、暗部克制，不产生自发光光晕。
- 同一画面避免同时出现多个太阳、月轮、光柱或巨大奇峰争夺焦点。

## 8. 参考图反推表

查看参考图后，在内部填写：

| 维度 | 需要确认的事实 |
|---|---|
| 画幅与镜头 | 横/竖画幅；广角程度；是否有明显畸变 |
| 相机位置 | 地面、台阶、檐下、桥上、空中或山崖 |
| 高度与朝向 | 贴地/人眼/俯视；仰拍/平视/斜俯 |
| 主体占比 | 主建筑位于何处，约占多少面积 |
| 空间层级 | 前景、中景、远景分别是什么 |
| 引导线 | 哪些实体线条汇聚，主消失点在哪里 |
| 尺度标尺 | 人物、门、树、栏杆如何说明建筑尺寸 |
| 大气遮挡 | 云、雾、逆光或阴影遮住哪些区域 |
| 色彩材质 | 石、木、瓦、地面与天空的主色和质感 |
| 视觉锚点 | 去掉细节后仍必须保留的独特关系 |
| 镜像关系 | 地面反射什么；强度、清晰度和衰减如何 |
| 天象对位 | 月轮、太阳或奇峰是否与门洞、长廊或主轴形成关系 |

先忠实保留视觉锚点，再替换失控色彩、廉价材质或错误建筑。不要把所有参考图都改写成低机位长阶。

## 9. 构图验收

输出前回答：

- 能否用一句话指出相机在哪里、朝哪里看？
- 能否按顺序说出至少五个景深层？
- 能否指出唯一主消失点和至少两组服务它的引导线？
- 人物是否落在中远景且明显小于柱基、门洞或台阶？
- 近景是否提供越框、遮挡或尺度压力，而非无意义装饰？
- 远景是否通过低对比与云雾继续延伸？
- 若地面高反射，倒影是否与实体、主光、拼缝和接触点一致？
- 若出现巨大月轮或月洞，它是否强化框景与主轴，而不是遮蔽建筑或成为孤立贴图？
- 移除材质和光效形容后，空间本身是否仍然成立？

任一关键答案为“否”时，先重构空间，再进入提示词精修。
